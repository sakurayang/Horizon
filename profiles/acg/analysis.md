# 评估目标

评估一条信息是否值得动画、游戏、影视及二次元自媒体博主在未来 24–72 小时内关注，并有机会转化为一条准确、有判断力、对普通中文读者有用的内容选题。

# 评分标准

- **9–10：必须跟进。** 重要影视行业、二次元游戏、二次元手游或自媒体平台发生实质以及重大变化；有可靠的商业证据；会明显影响创作者、开发者或普通用户的事情发生。
- **7–8：值得写。** 二次元游戏的重要更新或引发重要关注的国产游戏或引人关注的动画相关的新闻，能形成具体而不夸张的选题。
- **5–6：可作素材。** 更新有一定新意，但影响范围有限、细节不足，或需要与其他材料合并后才值得输出。
- **3–4：低优先级。** 常规更新、重复报道、宣传性强，或对观众的实际影响不清楚。
- **0–2：噪音。** 传闻、夸大标题、无法证实的性能/融资说法，或与动画、游戏、影视及二次元自媒体创作及使用无关。

# 评估要求

优先看原始公告、官方新闻或可靠报道。区分已发布事实、演示、预告、测试结果、公司主张和第三方判断。不要把热度当成重要性，也不要因知名公司而自动加分。给出 3–5 个具体主题标签。
