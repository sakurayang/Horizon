### [2005 年《战神》非官方原生 PC 移植发布首个公开版](https://www.3dmgame.com/news/202610/3958506.html) ⭐️ 6.0/10

Linux 内核 IPv4 TCP 路径中被披露存在释放后使用漏洞 CVE-2026-98432，CVSS 评分为 9.8。该漏洞仅影响 Linux；评论指出它并非 MPTCP 专属，但成功利用需要多核并行处理数据包，而且许多 ISP 路由器会丢弃带 IP 选项的报文，使互联网远程利用不太可能。评论还援引 Red Hat 称丢弃这类报文只能降低风险、并非完整缓解，并指出 Ubuntu 与 Red Hat 尚无补丁。

hackernews · oger · 10月31日 19:16 · [社区讨论](https://news.ycombinator.com/item?id=50319143)

**「背景：TCP 握手竞态导致的 UAF」** CVE-2026-98432 是 Linux 内核 IPv4 TCP 握手处理代码中的竞态条件，这类缺陷会让内核在释放某块内存后仍继续引用它，即 use-after-free。该编号由内核自身的 CVE 团队评为 9.8，而 Red Hat 的评分更低，理由是这个竞态窗口很难命中。漏洞影响 Ubuntu、RHEL 及其他 Linux 发行版，并非某个特定 TCP 扩展（如 MPTCP）专属。

**「处置影响」** 对运行受影响内核的多核 Linux 服务器，管理员应优先升级到发行版提供的修复内核；Red Hat 将升级到含修复的产品版本列为首选方案，缓解措施只能作为补丁前的临时手段。TheHackerWire 称已有公开的 PoC 参考，暴露在外的资产应尽快核查并按厂商公告处置。

**「社区讨论」** 评论最集中的分歧在于影响范围与修复节奏：有人强调标题去掉“Linux”会掩盖受影响系统仅限 Linux 的事实，也有人认为多核要求和 IP 选项过滤显著降低了实际风险。另有评论者批评 Ubuntu 和 Red Hat 作为面向服务器的发行版仍未提供补丁。
