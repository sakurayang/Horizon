## [Valhalla 项目首次预览：JEP 401 在 JDK 28 中为 Java 值对象重新定义 == 运算符](https://www.infoq.cn/article/8grNo7eCm3Rly0NV8bcS) ⭐️ 9.0/10

JEP 401 已作为预览功能集成到 JDK 28 中。该 JEP 引入了一个新的 \`value\` 类修饰符，用于创建没有对象标识的不可变实例，并从根本上改变了 \`==\` 运算符对这些对象的行为。 这代表了 Java 一次重大的范式转变，为更高效、扁平的内存表示铺平了道路，可以显著减少内存开销并提升以数据为中心的类的性能。它解决了开发者对简单数据承载类的意图与传统的 Java 对象固有的身份标识和开销之间长期存在的脱节问题。 该预览功能默认禁用，必须在编译时和运行时使用 \`--enable-preview\` 参数启用。启用后，包括基本类型包装类和 \`LocalDate\` 在内的多个 JDK 类将变为值类，这可能会带来迁移影响，并且像创建 \`Reference\` 这样的 API 将无法用于值对象。

rss · InfoQ 推荐 · 8月19日 04:25

**背景**: Valhalla 项目是 OpenJDK 的一个长期项目，旨在通过值类型和泛型特化等高级功能来增强 Java 语言和 JVM。在 Java 传统的对象模型中，每个对象都有唯一的身份标识，这也是 \`==\` 运算符所比较的内容，这导致了简单数据聚合体的内存和性能开销。JEP 401 是该项目的首个重要预览成果，引入了值对象的概念，这些对象仅由其字段值定义，缺乏身份标识。

## [冷原子量子存储器间纠缠距离提升至 420 公里，突破无中继理论极限](https://www.solidot.org/story?sid=85137) ⭐️ 9.0/10

中国科学技术大学等单位的研究人员成功实现了两个冷原子量子存储器间跨越 420 公里光纤的量子纠缠。这一成果在 230 公里以上距离突破了无中继量子纠缠分发的理论极限。 这一突破大幅提升了基于物质的量子比特（物质量子比特）间的纠缠距离，这是构建实用化大规模量子网络的基础条件。它为构建城际尺度的量子互联网奠定了基础，有望应用于远程量子通信、分布式量子计算和分布式量子传感等领域。 该成果基于团队此前的一系列突破，包括 2020 年实现的 50 公里光纤双节点纠缠，以及 2024 年在合肥构建的国际首个城域三节点量子存储网络。团队在 2026 年还进一步实现了百公里高保真双节点纠缠和器件无关量子密码分发。

rss · 奇客Solidot–传递最新科技情报 · 8月19日 10:06

**背景**: 量子存储器是传统计算机存储器的量子力学版本，它存储的是量子态（量子比特）而非经典的二进制信息。冷原子系统因其高度可控和纯净的特性，是制造高性能量子存储器的领先平台之一。量子纠缠是一种量子力学现象，相互纠缠的粒子无论相隔多远，其状态都会瞬间相互影响，是量子通信和量子计算的核心资源。所谓的“无中继理论极限”，指的是在不借助量子中继器（用于放大和纯化量子信号的中继设备）的情况下，通过光纤等信道直接分发量子纠缠所能达到的最大距离，这是构建长距离量子网络的主要技术障碍。
