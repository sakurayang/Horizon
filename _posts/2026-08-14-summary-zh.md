## [Azure Cosmos DB 严重漏洞链 CosmosEscape 曝光，暴露平台级主密钥](https://www.infoq.cn/article/L9IqUuWzSB4zgP0PBqG2) ⭐️ 9.0/10

Wiz Research 披露了 Azure Cosmos DB 中的一个严重漏洞利用链 CosmosEscape，攻击者可借此逃逸 Gremlin 查询沙箱，获取一个平台级的 &\#x27;Cosmos Master Key&\#x27;，从而获得对该服务上所有数据库的读写权限。微软在 2025 年 11 月收到报告后两天内阻断了存在漏洞的 Gremlin 入口点，但完全移除该主密钥并重建架构的工作持续到了 2026 年 7 月。 该漏洞是对主流云数据库服务中租户隔离机制的系统性突破，挑战了云安全的基本假设和共同责任模型。其影响不仅限于客户数据，由于 Cosmos DB 是 Microsoft Teams 和 Copilot 等自身服务的底层支撑，它也凸显了超大规模云平台中存在的集中化风险。 该利用链始于攻击者针对其自行控制的 Gremlin 数据库发起的一条特制查询，利用 .NET 反射逃逸沙箱，进而在多租户的 DB Gateway 上执行代码。值得注意的是，该漏洞没有公开的 CVE 编号或 MSRC 安全公告，也未明确说明暴露的时间窗口；微软表示修复已在服务端完成，客户无需采取任何行动。

rss · InfoQ 推荐 · 8月13日 03:53

**背景**: Azure Cosmos DB 是微软提供的全托管、多模型数据库服务。其中的 Apache Gremlin API 允许用户执行图查询，服务会在沙箱环境中将这些查询编译成 .NET 代码。文中提到的 &\#x27;Cosmos Master Key&\#x27; 是一个平台级凭据，可以获取任意 Cosmos DB 账户的主密钥，这一概念在微软的访问控制文档中有详细说明。
