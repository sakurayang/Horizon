微软发布了 dotnetup 公开预览版：这是一款跨平台、按用户安装和管理 .NET SDK 与运行时的工具，设计借鉴 rustup 和 nvm，不会写入 Program Files\\dotnet 或 /usr/share/dotnet。它跟踪的是安装意图，而非固定版本号；可以指定 latest、lts、preview、daily 等通道，或主版本 10、次版本 10.0、功能带 10.0.1xx 等目标，并读取最近的 global.json 以保持团队构建确定性；指定的精确版本在更新时保持不变。预览版之间的命令和行为可能变化，微软建议生产环境继续使用安装程序、包管理器或 Visual Studio。

### [Astra 声称可编辑权重修复 Qwen 循环问题](https://rikiyat.github.io/blog/weight-space-programming/) ⭐️ 6.0/10

一篇个人博客声称，Astra 可以直接读写小型模型的权重，并据此修复小型 Qwen 推理模型的循环问题、提升其数学表现。评论中引用的博客细节称，基线模型在 96 次练习回答中有 85 次跑到 32,768 token 上限，Astra 将循环归因于第 15、19 层 MLP 写入的一个方向，并从每层的 64 个输出列中减去该方向，涉及 131,072 个权重。当前可见材料主要是博客与 HN 讨论，尚无论文、代码或独立复现，作用对象也限于小模型，实际效果和可推广性仍待核实。
