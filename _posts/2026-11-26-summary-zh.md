### [B 站 Q3 营收 83.2 亿元，游戏收入同比降 7%](https://www.youxituoluo.com/535092.html) ⭐️ 7.0/10

Angular 团队公布了新编译器 Angular Preprocessor（ngp）：它用 Rust 和 Oxc 重写编译流程的分析阶段，以摆脱对 TypeScript 7 Go 版本已移除的 ts.Transformer API 的依赖。ngp 先由 Oxc 的 Rust 前端并行分析文件并解析 Angular 元数据，再交给现有 TypeScript 模板编译器生成运行时文件和 .ngtypecheck.ts 类型检查块，最后由 tsgo、tsrs、esbuild 或 Rolldown 独立完成类型检查与代码生成。大部分代码已在 10 月 8 日合入，约 37 万行的提交中约 5.6 万行为 Rust；Cédric Exbrayat 在最多 1714 个组件的项目上测试 Beta，测得冷构建快 2 至 3 倍，内存占用从 2.8GB 降至 1.4GB。该方案仍是部分重写，生产构建应继续使用 ngc，预计在 TypeScript 7.1 恢复编译器 API 后随 Angular 22 的某个小版本正式引入。

rss · InfoQ 推荐 · 11月26日 00:00

**「背景」** Angular 的现有编译器 ngc 一直封装 TypeScript 的 tsc，并借助 ts.Transformer API 在编译期把 @Component、@Pipe 等装饰器改写为运行时指令。TypeScript 7.0 的 Go 重写没有提供等价的跨语言接口，使这条依赖 JavaScript 转换 API 的路径无法继续；Angular 因而转向已在 Vite 中使用的 Rust 工具链 Oxc。
