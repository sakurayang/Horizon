## [DeepSeek 发布首个多模态 API 模型 DeepSeek-V4-Flash-Vision-Exp](https://www.ifanr.com/1676067?utm_source=rss&amp;utm_medium=rss&amp;utm_campaign=) ⭐️ 9.0/10

2026 年 8 月 21 日，DeepSeek 正式上线了其首个多模态 API 模型，名为 DeepSeek-V4-Flash-Vision-Exp，为其原有的文本模型 V4-Flash 增加了视觉理解能力。该模型对图像的计费价格与纯文本完全一致，每张图片最多消耗 384 个 token，并支持 base64 内联、外部 URL 和免费的 Files API 三种图片传入方式。 此次发布标志着 DeepSeek 正式进入多模态 AI 竞技场，与 OpenAI 的 GPT-4V 和 Google 的 Gemini 等成熟玩家直接竞争。其激进的定价策略使得图像处理成本远低于竞争对手，这可能会大幅降低开发者构建具备视觉能力的 AI Agent 和应用程序的门槛，并可能重塑市场格局。 文章中引用的评测显示，增强视觉能力的模型在七项 Agent 评测中有六项超越了其前身 V4-Flash-0731，并在多模态任务上甚至一度超过了某些硅谷顶级模型。该模型旨在与 DeepSeek 近期发布的 Agent 运行时框架 Harness 无缝协作，无需编写额外的适配代码。

rss · 爱范儿 · 8月21日 10:23

**背景**: DeepSeek 是一家知名的 AI 研究公司，以其大语言模型而闻名，V4 系列是其旗舰产品，在文本推理和代码生成方面表现出色。多模态 AI 指的是能够同时处理和理解多种类型数据输入（如文本和图像）的模型。在此次发布之前，DeepSeek 的模型主要是纯文本的，缺乏原生的视觉理解能力，而这被认为是高级 AI Agent 和应用程序的关键组成部分。

## [科学家发布史上最大的宇宙二维地图，包含 5.6 万亿像素。](https://newscenter.lbl.gov/2026/08/10/scientists-release-biggest-2d-map-of-the-universe/) ⭐️ 8.0/10

科学家发布了迄今为止最大、最全面的宇宙二维地图，这是一个包含近 40 亿个天体、拥有 5.6 万亿像素的星图。该地图可通过 Legacy Survey Sky Viewer 公开访问，预计将在未来数年内保持其权威性。 该地图是创建史上最大宇宙三维地图的基础数据集，对于研究宇宙膨胀和暗能量至关重要。它前所未有地开放了天文数据，既支持专业研究，也方便公众探索宇宙。 该地图是 DESI Legacy Imaging Surveys 项目的一部分，包含了恒星、星系、黑洞和小行星。交互式查看器中的每个光点都链接到详细的目录条目，使研究人员能够直观地检查潜在的研究目标。

hackernews · NKosmatos · 8月21日 18:36 · [社区讨论](https://news.ycombinator.com/item?id=49392200)

**背景**: 天文巡天系统性地对大片天空进行成像，以编录天体。暗能量光谱仪（DESI）是一个关键项目，它利用此类巡天测量数百万个星系的距离，并创建三维地图以研究暗能量。二维地图提供了天体在天空中的位置，而添加第三维以创建三维地图则需要距离测量（通常通过红移）。
