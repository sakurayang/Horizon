## [HTMX 4.0 发布，捆绑核心功能并进行多项改进](https://four.htmx.org/announcements/2026-08-28-htmx-4.0.0-is-released) ⭐️ 9.0/10

HTMX 库发布了其主版本 4.0，将 Idiomorph DOM 变形算法捆绑到核心中，引入了新的 \`&lt;multi-swap&gt;\` 标签以实现更清晰的多目标更新，并添加了原生 View Transitions API 集成。该版本于 2026 年 8 月 28 日发布，还包括显式的属性继承，并移除了旧的 localStorage 历史引擎。 此次发布代表了超媒体驱动的 Web 开发范式的一次重要演进，旨在以更低的感知复杂度提供更强大的功能。它巩固了 HTMX 作为重型 JavaScript 框架的一个引人注目的替代方案的地位，可能加速其在采用更简单的以服务器为中心的架构构建现代响应式界面中的应用。 尽管 HTMX 2.0 曾被宣布为最终版本，但团队为了兑现&\#x27;没有 3.0 版&\#x27;的承诺并交付一次重大的重构，直接跳到了 4.0 版本。该库保持了其约 14KB（压缩后）的小巧体积，其&\#x27;HTML over the wire&\#x27;和渐进增强的核心理念也保持不变。

hackernews · rmsaksida · 8月28日 13:28 · [社区讨论](https://news.ycombinator.com/item?id=49478178)

**背景**: HTMX 是一个开源的 JavaScript 库，它通过自定义属性扩展 HTML，使开发者能够直接在标记中访问 AJAX、CSS 过渡、WebSockets 和服务器发送事件。它倡导一种超媒体驱动的方法，即服务器发送 HTML 片段，由客户端将其交换到 DOM 中，这与依赖客户端 JavaScript 来渲染 JSON 数据的单页面应用程序形成对比。

## [DuckDB v2.0 预览版引入原生客户端/服务器模式与分布式能力](https://www.infoq.cn/article/9YLW3ZxLvrqxOVzSh9Y1) ⭐️ 9.0/10

DuckDB Labs 发布了代号为 &\#x27;Cyanoptera&\#x27; 的 DuckDB v2.0 预览版，该版本通过 quack 协议和新的 CONNECT SQL 语句引入了原生客户端/服务器模式，实现了分布式运行。此次发布还通过版本化的 C API 稳定了扩展生态系统，并引入了成熟的 VARIANT 类型以处理半结构化数据。 这标志着 DuckDB 从嵌入式、进程内数据库向分布式分析系统的重大架构转变，极大地扩展了其在数据工程和分析领域的应用场景。稳定的扩展 API 和服务器能力降低了生产部署和集成到大型多租户数据管道的门槛。 v2.0 预览版包含多项性能增强，如针对云存储的异步 I/O、新的基于 PEG 的 SQL 解析器以及原生的 BEFORE/AFTER 触发器。正式版计划于 2026 年秋季发布，目前已有预览版二进制文件可供测试。

rss · InfoQ 推荐 · 8月28日 09:00

**背景**: DuckDB 是一个开源的、列式存储的、进程内的 SQL 数据库管理系统（DBMS），专为高性能分析型（OLAP）查询而设计。它以单一二进制文件的简洁性、在消费级硬件上处理核外分析的能力以及丰富的 SQL 方言而闻名。此前，它主要作为嵌入式库在应用程序进程内运行，没有内置的用于客户端/服务器通信的网络支持。
