## [Remix 3.0 Beta 发布：彻底重写，放弃 React 转向 Web 平台原生能力](https://www.infoq.cn/article/s8IA8KgdrizgCEsQAOXr) ⭐️ 9.0/10

Remix 团队发布了 Remix 3.0 的 beta 预览版，这是一个从底层重新构建的版本，将框架从 React 迁移到了 Web 平台原生基础能力之上。此版本将 Remix 重新定位为一个完整的全栈体系，将路由、请求处理器、中间件、身份认证、数据管理和 UI 组件等能力统一纳入基于小型可组合软件包构建的架构中。 这标志着一个主流 Web 框架的范式转变，从以 React 为中心的模型转向直接构建在 Fetch API 等标准化 Web API 之上。这可能通过推动开发者更多地依赖 Web 标准而非框架特定的抽象，来显著影响全栈 Web 开发，有望提升互操作性并减少供应商锁定。 此次重写包含了一个基于 Fetch API 的新路由系统，控制器返回 Web Response 对象。在前端，Remix 保留了 JSX，但移除了 React 运行时，转而采用一个基于 Preact 的分支版本以及一个更命令式的编程模型。该框架还引入了“取消打包”的理念，其中运行时而非打包器成为资源的事实来源。

rss · InfoQ 推荐 · 8月2日 01:11

**背景**: Remix 是一个全栈 Web 框架，最初由 React Router 背后的团队创建，现由 Shopify 维护。它曾以其基于文件的路由、嵌套布局和与 React 的紧密集成而闻名。“Web 平台”指的是由 W3C 等标准组织定义的、构成 Web 基础的标准化技术集合（如 HTML、CSS、JavaScript 以及 Fetch 等 API）。Preact 是一个快速、轻量级的 React 替代品，具有类似的 API。

AI 研究员 Andrej Karpathy 推出了名为 &\#x27;Pelican&\#x27; 的新基准测试，旨在评估 AI 模型根据文本描述生成 3D 动画的能力。该基准通过这项创造性任务，专门测试模型对物理推理和空间关系的理解。 这很重要，因为它将 AI 评估从静态图像生成推向动态的 3D 世界构建，这是对模型掌握物理和物体交互能力的更有意义的测试。该领域的可靠基准对于追踪 AI 系统在物理世界推理和模拟方面的进展至关重要。 该基准建立在 Simon Willison 创建的 &\#x27;鹈鹕骑自行车&\#x27; SVG 非正式测试之上，但将其提升到了更复杂的 3D 动画领域。一些社区成员提醒，在此任务上的成功可能反映的是模型生成特定代码（如 three.js）的熟练度，而非真正的物理理解。

维基媒体基金会于 7 月 27 日拒绝自愿认可员工工会，并已雇佣以反工会或“破坏工会”工作而臭名昭著的 Littler Mendelson 律师事务所作为其法律代表。该基金会声明将要求美国国家劳工关系委员会（NLRB）来裁决工会组建事宜，此举被视为拖延进程的策略。 这一进展意义重大，因为它使运营维基百科等大型开放知识项目的非营利性维基媒体基金会，与苹果和星巴克等大型营利性科技公司使用的有争议的反工会策略站在了同一阵线。这标志着科技和非营利领域管理层对组织化劳工的立场可能趋于强硬，可能会影响其他面临类似工会推动的组织。 该基金会以其 342 名美国员工持有不同看法为由，拒绝自愿认可工会。通过坚持要求 NLRB 流程而非自愿认可，基金会可以启动更长的选举时间线，在此期间可以进行反工会宣传，包括可能具有强制性的会议。

rss · 奇客Solidot–传递最新科技情报 · 8月2日 14:04

**背景**: 在美国，工人可以通过雇主的自愿认可或由国家劳工关系委员会（NLRB）监督的正式选举程序来组建工会。自愿认可通常基于显示多数支持的卡片检查，速度更快且对抗性较低。Littler Mendelson 律师事务所在劳动法领域以代表资方而广为人知，并被描述为“破坏工会”的律所，曾在星巴克和苹果等公司自身的工会斗争中被雇佣。
